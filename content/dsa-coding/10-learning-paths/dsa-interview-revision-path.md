# Interview Revision Path

48-hour cram before a coding loop. Assumes you have seen these patterns before — focus on templates, one clean implementation each, and articulating trade-offs aloud.

## Day 1 — Core patterns (6 hours)

### Block 1 — HashMap & two pointers (90 min)

1. [Two Sum](/dsa-coding/01-arrays-hashmap-two-pointers/two-sum/) — complement map
2. [3Sum](/dsa-coding/01-arrays-hashmap-two-pointers/3sum/) — sort + two pointers
3. [Valid Palindrome](/dsa-coding/01-arrays-hashmap-two-pointers/valid-palindrome/) — converge pointers

### Block 2 — Sliding window (90 min)

Read [Sliding Window Template](/dsa-coding/09-interview-guide/sliding-window-template/), then:
1. [Longest Substring Without Repeating](/dsa-coding/02-sliding-window-prefix-sum/longest-substring-without-repeating-characters/)
2. [Max Consecutive Ones III](/dsa-coding/02-sliding-window-prefix-sum/max-consecutive-ones-iii/)

### Block 3 — Binary search (60 min)

Read [Binary Search Template](/dsa-coding/09-interview-guide/binary-search-template/), then:
1. [Binary Search](/dsa-coding/03-binary-search/binary-search/)
2. [Koko Eating Bananas](/dsa-coding/03-binary-search/koko-eating-bananas/) — search on answer

### Block 4 — Graphs (90 min)

Skim [Graph Cheat Sheet](/dsa-coding/09-interview-guide/graph-cheatsheet/), then:
1. [Number of Islands](/dsa-coding/06-graphs/number-of-islands/) — grid DFS
2. [Rotten Oranges](/dsa-coding/06-graphs/rotten-oranges/) — multi-source BFS

### Evening — light review (30 min)

Scan [Top 30 Must-Solve](/dsa-coding/09-interview-guide/top-30-must-solve/) and flag any problem you cannot solve in 25 minutes.

## Day 2 — Depth & timed practice (6 hours)

### Block 1 — Trees (90 min)

[Tree Cheat Sheet](/dsa-coding/09-interview-guide/tree-cheatsheet/) + [Validate BST](/dsa-coding/05-trees/validate-binary-search-tree/) + [Binary Tree Right Side View](/dsa-coding/05-trees/binary-tree-right-side-view/)

### Block 2 — Backtracking (60 min)

[Word Search](/dsa-coding/04-recursion-backtracking/word-search/) + [Generate Parentheses](/dsa-coding/04-recursion-backtracking/generate-parentheses/)

### Block 3 — Dynamic programming (90 min)

[DP Cheat Sheet](/dsa-coding/09-interview-guide/dp-cheatsheet/) + [Coin Change](/dsa-coding/08-dynamic-programming/coin-change/) + [House Robber](/dsa-coding/08-dynamic-programming/house-robber/)

### Block 4 — Advanced graph (45 min)

[Alien Dictionary](/dsa-coding/07-advanced-graphs/alien-dictionary/) — topological sort edges from adjacent words

### Block 5 — Mock + review (75 min)

45-minute timed session: one medium array/graph + one medium DP. 15 minutes post-mortem; cross-check answers on [Top 55](/dsa-coding/09-interview-guide/top-55-interview-questions/).

## Night before

- Re-read templates only — no new problems
- Sleep 7+ hours; verbalize pattern choice before coding in the interview
