Use this handbook as a guided discovery path rather than a catalog. Begin with the foundations, examine each enterprise discovery domain, and turn the findings into modernization decisions and architecture deliverables.

## Learning path

| Stage | Outcome | Start here |
| :--- | :--- | :--- |
| **1. Foundations** | Establish scope, participants, evidence, and discovery cadence | [Introduction](introduction/) |
| **2. Discovery domains** | Build an evidence-based view of business intent, systems, constraints, and operations | [Business Discovery](business-discovery/) |
| **3. Decisions and outputs** | Evaluate modernization options, risks, and required architecture artifacts | [Modernization Discovery](modernization/) |
| **4. Applied resources** | Run workshops and reinforce the framework with reusable assets and scenarios | [Templates](templates/) |
