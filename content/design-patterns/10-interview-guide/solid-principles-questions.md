# SOLID Principles Questions

1. How do you identify multiple reasons to change in a class during code review?
2. When is splitting a class by SRP premature and what signals tell you to wait?
3. How does OCP apply to adding a new payment type without modifying checkout?
4. What is the difference between open for extension and open for modification in practice?
5. Why does Rectangle/Square violate LSP and how would you model dimensions correctly?
6. How do preconditions and postconditions formalize substitutability in APIs?
7. When does a fat interface force clients to depend on methods they never call?
8. How would you split a multi-function printer interface for ISP compliance?
9. What dependency direction violation appears when a domain entity imports JDBC?
10. How does DIP relate to hexagonal ports without conflating the two concepts?
11. How do you apply SOLID when refactoring a 2,000-line OrderManager god class?
12. What smell-to-fix map entry would you use for feature envy across services?
13. How does SRP interact with transaction boundaries in a place-order use case?
14. When does OCP conflict with YAGNI on a greenfield microservice?
15. How do you explain LSP to a team that treats inheritance as code reuse only?
16. What ISP refactoring would you prioritize before adding a fourth client to a shared interface?
17. How does DIP enable test doubles without a DI framework?
18. What SOLID letter breaks first in an anemic domain model and why?
19. How do SOLID principles compose when designing a notification subsystem?
20. When is a single class cohesive enough to satisfy SRP despite multiple public methods?
21. How do sealed classes in Java 17 affect OCP for expression-based extension?
22. What LSP violations appear in mock-heavy tests that never use real subclasses?
23. How does ISP reduce rebuild times in large multi-module Maven projects?
24. How would you teach DIP using a payment gateway example without Spring jargon?
25. What SOLID regression risks appear after aggressive microservice extraction?
