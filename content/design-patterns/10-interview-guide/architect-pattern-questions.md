# Architect Pattern Questions

1. How do you weigh Flyweight memory savings against code complexity for a glyph editor?
2. What maintenance burden does the Visitor pattern impose when the element hierarchy changes frequently?
3. What happens to open-closed compliance when every new feature adds a new Strategy class?
4. What tradeoff do you make between elevator SCAN scheduling simplicity and fairness?
5. How do you decide between in-process Observer and out-of-process event bus for domain events?
6. How do you measure whether a pattern reduced change frequency versus added ceremony?
7. What team skill gap makes Visitor or Memento a poor choice regardless of fit?
8. When does golden hammer Singleton usage invalidate performance tuning elsewhere?
9. How do Flyweight and Singleton interact — when are both present in the same subsystem?
10. What comparison matrix would you use for creational patterns in a platform SDK?
11. How does hexagonal architecture compare to layered for a modular monolith?
12. What three questions disambiguate Decorator, Proxy, and Bridge in a code review?
13. How do preconditions and postconditions formalize substitutability in APIs?
14. When does OCP conflict with YAGNI on a greenfield microservice?
15. What SOLID letter breaks first in an anemic domain model and why?
16. What SOLID regression risks appear after aggressive microservice extraction?
17. What scheduling algorithm tradeoffs exist between SCAN and LOOK for elevator dispatch?
18. How do you design rider-driver matching with surge pricing in ride sharing?
19. What geospatial indexing concerns affect nearest-driver queries in ride sharing?
20. How do you scope an LLD to in-memory versus distributed when the prompt is ambiguous?
21. How would you extend elevator LLD to multiple shafts and floor requests?
22. What bounded context signals tell you to split a monolith before patterns help?
23. What ADR would you write choosing hexagonal over layered for a new payment service?
24. How do domain events differ from integration events in a notification architecture?
25. How do you detect golden hammer pattern adoption in architecture reviews?
26. What team practices prevent anemic domain models in DDD initiatives?
27. How do you push back when stakeholders demand a pattern for every ticket?
