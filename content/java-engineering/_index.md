You already work in Java. This is a **fast interview refresh**, not a course and not a tour of implementation internals.

**6 cheat sheets · about 2–3 hours · Java 8 → 25**

## Finish in This Order

| # | Cheat sheet | Refreshes | Time |
| :--: | :--- | :--- | :--: |
| 1 | [Core Java](/java-engineering/language-fundamentals/) | OOP choices, contracts, exceptions, generics, streams | 25 min |
| 2 | [Collections](/java-engineering/collection-selection-matrix/) | Choosing structures, complexity, concurrency | 20 min |
| 3 | [Concurrency](/java-engineering/java-threading-interview-guide/) | Executors, safety, async, virtual threads | 30 min |
| 4 | [JVM in Production](/java-engineering/jvm-memory-gc-oom-guide/) | GC, OOM, dumps, incident diagnosis | 25 min |
| 5 | [Modern Java](/java-engineering/java-version-migration-guide/) | Java 8/11/17/21/25 and migration judgment | 15 min |
| 6 | [Interview Sprint](/java-engineering/top-100-java-interview-questions/) | High-signal questions and architect scenarios | 30 min |

## Depth Policy

Start with the decision and a production example. Explain internals only when the interviewer explicitly asks **how it works underneath**.

| Interview level | Expected answer |
| :--- | :--- |
| 6+ engineer | Correct choice, concise reason, common pitfall |
| Lead | Trade-off, failure mode, observability |
| Architect | System impact, migration/operability decision, evidence from production |
